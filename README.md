# 딮기 시그널 (DK SIGNAL)

도란과 디플러스 기아 2027 로스터 5인의 **공식 경기 · 솔로랭크**를 한 화면에서 보는 팬 대시보드 PWA입니다.

- 라이브: https://schl410-hub.github.io/dk-radar/
- 단일 파일 미리보기: `preview/dk-radar-preview.html`
- 테마: **다크 네온 민트**(기본, `#05090F` + `#00F5C4`) ↔ **소프트 민트 글래스**(파스텔 민트 + 화이트 글래스)

## 지금 동작하는 것 (v2 · 딮기 시그널)

- **실시간 테마 전환**: 헤더 우측 `다크 / 소프트` 버튼. 선택은 `localStorage`에 저장되고 첫 페인트 전에 적용됩니다. 두 테마 모두 글래스 카드·보더·글자색이 따로 튜닝되어 있습니다.
- **탭 4개**: 홈 / 공식일정 / 경기로그 / 기록실
- **5인 상태 보드**: 도란 · 카나비 · 쇼메이커 · 스매쉬 · 딜라이트 타일을 누르면 최애 포커스 배너·하이라이트·전적표가 함께 바뀝니다. 타일에는 티어/LP, 최근 5경기 승패 바, 마지막 경기 시점이 표시됩니다.
- **최애 포커스 배너**: 선택 선수의 티어·LP·최근 5경기·마지막 경기, 솔랭 알림 벨
- **최근 5경기 하이라이트**: 대형 W–L, 승률, KDA(합계·평균), 경기별 챔피언/ KDA 카드
- **알림 설정 (localStorage 저장)**
  - **선수별 솔랭 알림**: 5명 각각 ON/OFF. 기본값은 도란만 ON.
  - **DK 공식 경기 알림**: 일정·시작 알림 별도 ON/OFF. 홈 알림 카드와 공식일정 탭 양쪽에서 같은 값으로 동기화됩니다.
  - **테스트 알림**은 현재 선수의 솔랭 알림 → 경기 알림 순서로 켜진 설정을 골라 실제 서비스워커 알림을 보냅니다. 모두 꺼져 있으면 앱 안 배너로 안내합니다.
- **한 줄 응원**: 선택 선수에게 응원 한 줄을 남기고 기기에 저장(최대 5줄, 삭제 가능)
- **솔로랭크 카드**: 티어/LP·시즌 전적·최근 경기 표(챔피언, 포지션, 승패, K/D/A, 시간, 서버 표시)
- **경기로그 탭**: 승/패 필터
- **공식일정 탭**: 다음 경기 카드(경기 알림 토글 포함), 월즈 2026 여정, 선수별 최근 공식 경기
- **기록실 탭**: 2026 시즌 대회별 세트 전적, 월즈 결과
- **PWA**: manifest + 서비스 워커 오프라인 캐시, 디플러스 기아 공식 로고 기반 아이콘(192/512/maskable/apple-touch/favicon/badge)
- **로컬 알림 테스트**: 서비스 워커 `showNotification`. 권한이 없거나 파일 뷰어면 앱 안 푸시 배너로 대체

## 데이터

`data.js`의 5인 솔로랭크·대회 기록은 **2026-11-26에 확인한 KO.LOL · OP.GG · u.gg 공개 전적**입니다. 자동 갱신은 하지 않습니다.

## 아직 안 되는 것 (v2 서버 과제)

실시간 감지·백그라운드 푸시는 서버가 필요합니다.

1. 라이엇 API 키 + OP.GG/공식 데이터 폴링 (cron)
2. 새 솔로랭크 게임 감지 → Web Push (VAPID) 로 구독 기기 발송 (선수별·경기 알림 구독 구분)
3. `sw.js` 의 `push` 핸들러가 이미 준비되어 있어, 서버에서 보내기만 하면 됩니다.

추천 구성: Vercel(또는 Cloudflare Workers) + Cron + Supabase/KV에 구독 저장 + `web-push` 라이브러리.

## 파일

```
index.html            화면 뼈대 (테마 부트스트랩 포함)
styles.css            듀얼 테마 토큰 + 컴포넌트 스타일
data.js               선수·경기·대회 기록 (2026-11-26 확인)
app.js                탭/선수 전환, 테마, 알림 설정, 표 렌더, 응원 저장
manifest.json         PWA 설정 (manifest.webmanifest 와 동일 내용)
sw.js                 서비스 워커 (캐시 + 알림)
logo/dpluskia.svg     디플러스 기아 공식 로고
icons/                앱 아이콘 (로고 기반)
fonts/                Pretendard 서브셋 (UI 글자만, ~89KB)
concepts/             초기 디자인 시안 3종 (참고용)
preview/              단일 파일 프리뷰 (자동 생성)
tools/make_preview.py 프리뷰 빌드
tools/make_icons.py   아이콘 생성 (Playwright + Pillow)
tools/make_font.py    Pretendard 서브셋 생성
tools/verify.py       390×844 브라우저 검증 + 스크린샷
```
