# DK 레이더 (DK RADAR)

도란과 디플러스 기아 2027 로스터 5인의 **공식 경기 · 솔로랭크**를 한 화면에서 보는 팬 대시보드 PWA입니다.

- 라이브: https://schl410-hub.github.io/dk-radar/
- 테마: 디플러스 기아 민트 (#00D4A4 / #0AC8A2 / 배경 #F2FBF9)

## 지금 동작하는 것 (v1)

- **탭 4개**: 전체 피드 / 공식 경기 / 경기 기록 / 대회 기록
- **선수 전환**: 도란 · 카나비 · 쇼메이커 · 스매쉬 · 딜라이트 (히어로 카드, Riot ID, OP.GG 링크, 최근 솔로랭크 표가 함께 바뀜)
- **솔로랭크 카드**: 티어/LP·시즌 전적·최근 경기 표(챔피언, 포지션, 승패, K/D/A, 시간, 서버 표시)
- **경기 기록 탭**: 승/패 필터
- **PWA**: 홈 화면 설치(manifest + 아이콘), 서비스 워커 오프라인 캐시
- **로컬 알림 테스트**: `[테스트]` 버튼 → 서비스 워커 `showNotification`으로 실제 알림. 권한이 없으면 앱 안 푸시 배너로 대체
- **솔랭 알림 켜기/끄기**: 상태를 localStorage에 저장 (v1은 표시용)

## 아직 안 되는 것 (v2 과제)

실시간 감지·백그라운드 푸시는 서버가 필요합니다.

1. 라이엇 API 키 + OP.GG/공식 데이터 폴링 (cron)
2. 새 솔로랭크 게임 감지 → Web Push (VAPID) 로 구독 기기 발송
3. `sw.js` 의 `push` 핸들러가 이미 준비되어 있어, 서버에서 보내기만 하면 됩니다.

추천 구성: Vercel(또는 Cloudflare Workers) + Cron + Supabase/KV에 구독 저장 + `web-push` 라이브러리.

## 파일

```
index.html            화면 뼈대
styles.css            민트 테마 스타일
data.js               선수·경기·대회 기록 (2026-11-26 확인)
app.js                탭/선수 전환, 표 렌더, 알림 로직
manifest.webmanifest  PWA 설정 (manifest.json 과 동일 내용)
sw.js                 서비스 워커 (캐시 + 알림)
icons/                앱 아이콘 (도토리 + 레이더)
fonts/                Inter 라틴 가변폰트 (셀프호스트)
tools/make_icons.py   아이콘 생성 스크립트
```
